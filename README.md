AquaPro Dive Shop - Tienda de artículos de buceo

Proyecto de e-commerce desarrollado con **React + Vite** como parte de la pre‑entrega del curso de React JS. La aplicación simula una tienda online especializada en equipamiento de buceo, ofreciendo un catálogo de productos, formulario de alta, carrito de compras y una sección informativa del equipo.
